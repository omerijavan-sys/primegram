# Liquid Prime

Build a legendary social media application from scratch called 'PRIME'. The UI must strictly follow the iOS 26 'Liquid Glass' design language.

Core Aesthetic Principles:

Liquid Glass Material: All UI elements (cards, nav bars, buttons) must behave like physical glass. They should refract the content behind them and show dynamic specular highlights that shift when the user scrolls or tilts.

Adaptive Translucency: Interfaces should not be flat. Use variable opacity (20%-80%) where the material intelligently adapts its tint based on the content beneath it.



Dynamic Morphing: Navigation bars and tab bars must 'liquidize'—shrinking fluidly into floating pills when scrolling down and expanding with a 'drop-of-water' elasticity when scrolling up.



Feature Set:

The Fluid Feed: A vertical stream of high-resolution images. Each post should sit inside a Liquid Glass container with soft, hyper-realistic depth shadows.

Glassmorphic Navigation: A bottom tab bar that looks like a single piece of molded clear glass, reflecting the colors of the feed posts.

Haptic UI: Ensure all buttons have a 'depth-press' animation, appearing to sink into the 'liquid' surface of the screen.

Technical Requirements:

Use Next.js, Tailwind CSS, and Framer Motion.

Use Three.js or WGL Shaders to achieve the real-time glass refraction and lensing effects.

The typography must be ultra-clean (San Francisco style) with dynamic weight scaling.



Optimize specifically for 'In-Cell' punch-hole displays to maximize screen real estate."
